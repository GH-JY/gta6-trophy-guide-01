Leonida Ledger is an offline guide and tracker for all 55 Grand Theft Auto VI PlayStation 5 trophies. Every trophy gets an original two-paragraph route with its sources listed beside it, twelve missable windows are flagged where they happen, and a seven-stage roadmap carries the list from the first mission to the 100% audit. Search, kind and grade filters, a hide-earned switch and a spoiler shield keep the list readable at any point in a run; progress saves in the browser and moves between machines as a small JSON file. Keyboard-first navigation and a dense split view make it comfortable on a laptop, and the whole thing is plain static files with no build step and no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
