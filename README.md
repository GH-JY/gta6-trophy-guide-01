An offline guide and tracker for all 55 Grand Theft Auto VI PlayStation 5 trophies: original guides with the source named beside them, a seven-stage roadmap to the platinum, missable windows, kind and grade filters, a spoiler shield, and browser-saved progress you can export and import as JSON. Plain static files, no build step, no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
